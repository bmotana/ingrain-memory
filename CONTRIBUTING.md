# Contributing

Thanks for contributing to Recall CLI.

## Development setup

1. Use Python 3.10 or later.
2. Create and activate a virtual environment.
3. Install the project and development tools with `python -m pip install -e ".[dev]"`.
4. Before opening a pull request, run `ruff check .`, `ruff format --check .`, and `python -m pytest`.

## Pull requests

Keep pull requests focused, include tests for behavioural changes, and update the README when user-facing behaviour changes. Use clear commit and pull-request descriptions that explain the reason for the change.
