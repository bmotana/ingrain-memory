# Legacy Prototypes

This folder contains the original prototype scripts developed during early experimentation:

- `steping_stone.py` - Initial prototype for single-sentence word-by-word typing recall.
- `v2_not_for_typing.py` - Prototype for oral/flashcard recall with timed view and self-grading.
- `V3_for_coding.py` - Prototype for multi-line code/text memorization.

These ideas have been unified, modularized, and enhanced into the `recall` CLI application in `src/recall`.
